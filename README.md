# LOSS LESS Foundation — Website

A responsive React + Vite + TypeScript website starter for `loss-less-foundation.github.io`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Push this project to the repository `loss-less-foundation/loss-less-foundation.github.io` on the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the source.
4. Push to `main`; the included workflow builds and deploys the site.

This is a user/organization GitHub Pages repository, so Vite uses `base: "/"`.

## Brand assets

The supplied LOSS LESS Brand Identity System 1.0 SVG symbol and favicon are in `public/brand/`.

## Before public launch

- Confirm the legal/organizational status and preferred institutional description of the Foundation.
- Add reviewed public PDF editions and link them from the document catalogue.
- Add contact details and official social links only after they are confirmed.
- Review all research claims. The site intentionally describes LOSS LESS as a proposed framework under development.
- Confirm the repository's Pages settings and deployment permissions.
